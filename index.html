Current experiment

BOTH + Stops-only breakout grid

Configuration

Direction
BOTH
Pending kind
STOPS ONLY
Reference behaviour
Buy stops above / sell stops below

Hypothesis

When price breaks and continues, only orders in the breakout direction trigger. The opposite-side stops remain pending unless price reverses through them.

Critical limitation

This is not permanently one-directional. A reversal can activate the previously idle opposite-side stops; exposure, drawdown and basket-exit rules determine whether that is acceptable.

How to read this site

Research discipline

  1. State the hypothesis before testing.
  2. Record the symbol, period, settings and data source.
  3. Separate observations from conclusions.
  4. Validate promising variants in MT5 with the exact broker specification.
