Import MT4 / MT5 history

Choose a local CSV/TSV export. Parsing happens only in this tab. Supported reasonably: MT4 Account History order rows, and MT5 Deal history where several deal rows belong to one position (only closed / out-style P&L rows are counted). Balance, credit, deposit and withdrawal rows are ignored. Non-standard broker layouts may need different headers.

Expected columns and honest limits

The importer looks for common headings such as Ticket/Order/Deal, Open Time, Close Time, Symbol/Item, Type, Volume/Lots, Open/Close Price, Commission, Swap, Profit, and (for MT5) Entry. Comma, tab, or semicolon separators are detected from the file. If your export uses unusual labels, rename the header row to match those names or adapt the sample file.

Scope: this is a lightweight local summariser for closed-trade P&L, not a full Tradezella replacement. It does not reconcile open positions, partial fills across exotic report formats, or broker-specific statement PDFs. Prefer Account History / Deal History CSV with a header row.

Current experiment

BOTH + Stops-only breakout grid

Configuration

Direction
BOTH
Pending kind
STOPS ONLY
Reference behaviour
Buy stops above / sell stops below

Hypothesis

When price breaks and continues, only orders in the breakout direction trigger. The opposite-side stops remain pending unless price reverses through them.

Critical limitation

This is not permanently one-directional. A reversal can activate the previously idle opposite-side stops; exposure, drawdown and basket-exit rules determine whether that is acceptable.

How to read this site

Research discipline

  1. State the hypothesis before testing.
  2. Record the symbol, period, settings and data source.
  3. Separate observations from conclusions.
  4. Validate promising variants in MT5 with the exact broker specification.
